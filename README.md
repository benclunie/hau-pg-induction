# Applied ecology postgraduate induction

Harper Adams University · Dr Ben Clunie

A 20-slide interactive Quarto / RevealJS presentation with a research-group staff organogram, visible discussion prompts and links to the live university research pages.

## Present

[Open the presentation](https://benclunie.github.io/hau-pg-induction/), or download `index.html` and open it in a browser. Use arrow keys to advance, Esc for the overview and S for speaker notes. Links to research groups open in a new tab.

## Edit

Download and extract `HAU_PG_Induction_Quarto_Source.zip`. Open the QMD in Positron or run `quarto preview HAU_PG_Induction.qmd` in the extracted project folder. Render with `quarto render HAU_PG_Induction.qmd`, then replace `index.html` with the generated `_site/HAU_PG_Induction.html`. See the project README for content and source notes.

Staff-group membership checked against the official Harper Adams research pages on 17 September 2026. The diagram shows group affiliation, not line-management reporting.
